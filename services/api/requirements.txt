# Minimum floors rather than exact pins.
#
# WHY: exact pins (==) freeze you to versions that may predate your Python.
# pydantic-core, asyncpg, bcrypt and Pillow all ship compiled code, so if no
# prebuilt wheel matches your interpreter, pip silently falls back to building
# from source -- which on Windows means a Rust/C toolchain and a 20-minute
# hang. Floors let pip resolve to whatever has a wheel for your version.
#
# Install with:
#   python -m pip install --only-binary=:all: -r requirements.txt
#
# --only-binary=:all: makes pip REFUSE to compile. If something genuinely has
# no wheel for your Python you get a clear error in seconds instead of a hang.
