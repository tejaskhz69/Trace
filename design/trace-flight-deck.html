Shipping it

Four deploys, in the order that unblocks the most work.

API — Railway

FastAPI is already the shared brain: both clients hit it. Point Railway at services/api, attach Postgres.

  1. Set JWT_SECRET explicitly, or every restart signs everyone out.
  2. Add the web origin to CORS — a browser really does send Origin.
  3. Run the ingestion scripts once to seed foods.

Web — Vercel

A new apps/web workspace, its tokens generated from the same source as the app's.

  1. vercel --prod from the workspace root.
  2. NEXT_PUBLIC_API_URL → the Railway URL.
  3. Camera routes render the “scanning needs the app” card, never a dead button.

Strava — OAuth + webhook

calories lives only on DetailedActivity, so each new ride costs a second call against a 2,000/day budget.

  1. Scope activity:read_all so private rides come through.
  2. Ack the webhook POST inside 2 s or it retries.
  3. Dedupe against Apple Health on start time + distance.
  4. Delete imported rides on disconnect — their terms require it.

App — EAS

Expo builds in the cloud; TestFlight puts it on your phone. HealthKit needs a development build.

  1. eas build --profile preview --platform ios.
  2. EXPO_PUBLIC_* is inlined at build time — a changed URL needs a new build.
  3. eas submit once the five tabs feel right.
